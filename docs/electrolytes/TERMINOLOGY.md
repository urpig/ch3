# 第三章科學名詞小字典（本機暫存）

- 詞條：138 個，含定義、例子、迷思提醒、必要符號與相關名詞。
- 沿用第一章的小字典樣式：側欄入口、12 張卡片篩選、中文／化學式搜尋、課文首次出現名詞的虛線按鈕。
- 每卡先顯示 3 個關鍵用語，其他詞條按需查閱；不增加答題或解鎖門檻。
- 開啟原生 dialog；可用關閉按鈕、Esc 或外側背景關閉，並返回原本焦點。
- 避開輸入框、按鈕、選項、圖解與即時讀數；長詞優先，避免把 H₂O 內的 H₂ 誤標為氫氣。
- 僅修改本機來源與離線版本，沒有 commit、push 或發布這次修改。
